Add the PDF of the work this annotation goes with — one student’s pages, or a whole class scanned into one file. Pick this student’s pages and they’re saved as their own PDF, under the same file name as above with STUDENT_WORK on the end. Nothing here is uploaded anywhere — the form autosaves to this browser only, and the PDF is built and downloaded locally.
