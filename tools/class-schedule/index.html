Colours

Each class gets its own colour, and the same name is the same colour everywhere. Give two names one colour (say Sci 8-4 and Science 8-4) by picking it for both.

Save and share

Your schedule is kept in this browser. To move it or give a copy to a colleague, save a file or copy a link.

A link leaves out the logo. Clear the classes keeps the grids and times.

A grid is one table of days (or rotation letters) and periods. Most schools need one; a second suits a day with its own bell times, such as a Friday rotation.
